# Avaliação Vestibular

Ficha de avaliação fisioterapêutica neurofuncional para disfunção vestibular (TCC), em 14 etapas, com escores calculados na hora. Agora com login, avaliações salvas em banco, listagem e backup em JSON.

Stack: Next.js 16 + Postgres (Neon), deploy na Vercel. Para rodar e desenvolver, veja `CLAUDE.md`.
