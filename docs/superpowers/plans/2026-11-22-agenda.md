# Agenda Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agenda compartilhada em `/agenda` (mês + linha do tempo do dia, eventos sobrepostos lado a lado).

**Architecture:** Tabela `eventos` no Postgres, rotas REST em `app/api/eventos` no padrão de `app/api/avaliacoes`, validação e consultas em `lib/eventos.ts`, cálculo de colunas puro em `lib/agenda-layout.ts`, tela client em `app/agenda/Agenda.tsx`.

**Tech Stack:** Next.js 16 (App Router), `pg` com SQL puro, React 19, CSS em `app/app.css`. Testes das funções puras com `node --test` (type stripping do Node).

**Spec:** `docs/superpowers/specs/2026-11-22-agenda-design.md`

## Global Constraints

- Sem dependências novas.
- Toda rota confere `sessaoAtual()`; autor e `atualizado_por` vêm da sessão.
- Título obrigatório (≤ 120), participantes ≤ 500, `fim > inicio`, mesmo dia.
- `dia` = `date`, `inicio`/`fim` = `time` — sem conversão de fuso. "Hoje" = data local do aparelho.
- 390px e 1366px sem rolagem horizontal; alvos ≥ 44px; inputs 16px; sem `alert()/confirm()`.
- Texto em português do Brasil; design system Vestibular Clínico (um acento, bordas, IBM Plex Mono em números).

## Review Focus

- Evento que começa exatamente quando outro termina (10:00–11:00 e 11:00–12:00): **não** é sobreposição, ambos em largura total.
- Cadeia A sobrepõe B, B sobrepõe C, A não sobrepõe C: mesmo grupo, 2 colunas, C reaproveita a coluna de A.
- Evento fora de 07–19h (ex.: 06:00 ou 21:30): a linha do tempo se estende para mostrá-lo.
- `fim <= inicio` ou dia inválido no corpo: 400 com mensagem, nada gravado.
- Sessão expirada durante salvar/excluir: vai ao login com `voltar=/agenda`.
